ZA量化（C 直连版） V1.3.1 使用说明
====================================

【启动】
双击安装目录中的 ZA量化-C直连版.exe（或桌面/开始菜单快捷方式）。
首次运行自动生成配置文件，并打开浏览器访问 http://127.0.0.1:8000

【天勤账户】
首次打开页面会弹出登录框，输入天勤账号（https://www.tqsdk.com 免费注册）与密码，
点"保存并连接"。密码优先保存在 Windows 凭据管理器；不可用时退回本机
.tqsdk\credentials.json 明文文件，请妥善保管，不要分享凭据文件。
下次启动自动登录；点页面右上角"账户"按钮可随时更换账号。

【合约搜索】
登录并连接天勤后，在搜索框输入名称或代码，向天勤查询当前挂牌合约。
例如：烧碱、纯碱、棕榈油2701、p2701、SA2701。
启动和空搜索不下载完整合约目录；搜索结果本身不持续订阅行情。
加入自选后持续更新行情；打开非自选合约详情时临时订阅，离开后释放。
查询失败可按回车重试；没有搜索结果与网络查询失败会分别提示。

【更新后确认】
请先关闭旧版 ZA量化 的运行窗口，再启动本版本，确认网页左上角显示 V1.3.1。
两版本共用同一端口；旧程序仍在运行时，启动器会复用其页面，导致继续使用旧接口。
不需要删除旧合约缓存。升级前后请保留原配置和自选数据。

【功能】
- 行情与五档盘口实时刷新（交易时段）
- 专业 K 线：1/5/15/30/60 分钟 + 日线，滚轮缩放/拖拽平移/十字光标
- 多因子决策评估：方向/评分/止损/目标/手数建议（仅供参考，不构成投资建议）
- 四档持有计划：超短线 5–30 分钟且不隔夜、短线 1–3 个交易日、中线 2–4 周、长线 1–3 个月
- 每档风险分别设置，金额与权益比例取更严格值；一手超过预算时建议 0 手
- 图表周期与评估模式独立；历史不足、报价过期或临近到期时显示提示
- 中长线分析当前合约，需要至少 35 根完整周线；系统不负责自动平仓或换月

【技术路线】
本版本 = C 直连版（直接实现天勤 DIFF 协议），安装包包含 Python 后端和网页界面。

【常见问题】
- 页面提示"未配置/未登录"：先完成天勤账户登录
- 非交易时段无实时报价属正常现象
- 退出：直接关闭运行窗口即可
