# 练习03：自己调一次接口（操作题）

> 对应 docs/10 第 4 章。目标：不用前端，亲手从后端拿到数据——这是前后端分离开发的"hello world"。

## 步骤

1. 确认后端在跑：项目根目录执行 `python main.py`（或 C 直连版 exe 已在运行）；
2. 浏览器访问：`http://127.0.0.1:8000/api/v1/status`——你应该看到一段 JSON；
3. 把下面每个地址都访问一遍，**用一句话记录每个接口返回了什么**：

   - `http://127.0.0.1:8000/api/v1/instruments?keyword=rb`
   - `http://127.0.0.1:8000/api/v1/quote/SHFE.rb2610`
   - `http://127.0.0.1:8000/api/v1/kline/SHFE.rb2610?period=300&count=10`
   - `http://127.0.0.1:8000/api/v1/decision/SHFE.rb2610`

4. 再访问一个**故意写错的**地址：`http://127.0.0.1:8000/api/v1/quote/不存在.abc`
   观察后端怎么告诉你"错了"（状态码 + 中文原因）；
5. 进阶：在 VS Code 里新建 `spike.py`，用 Python 拿同样的数据：

   ```python
   import requests
   r = requests.get("http://127.0.0.1:8000/api/v1/status", timeout=10)
   print(r.status_code)          # 状态码：200=成功
   print(r.json())               # JSON 文本 → Python 字典
   ```
