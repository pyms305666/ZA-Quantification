# 练习10：前端加"结算价"显示（操作题）

> 对应 docs/13 §4.5 的报价头渲染。练"三件套配合"：HTML 摆骨架 → JS 填数据。
> 结算价（settlement）是当天结算用的官方均价，在 DIFF 行情快照的字段名是 `settlement`。

## 步骤

1. **HTML**：打开 `static/index.html`，在"昨结"那格旁边加一格：
   ```html
   <div><label>结算</label><span id="m-settlement">--</span></div>
   ```
   （照抄"昨结"那格的写法，只改 id 和文字）
2. **JS**：打开 `static/app.js`，找到 `renderQuoteBar` 里 `set("m-preclose", q.pre_close);` 一行，
   在它后面照葫芦画瓢加：
   ```js
   if (q.settlement != null) set("m-settlement", q.settlement);
   ```
   （`set` 是文件里现成的小工具：填数字+按涨跌染色）
3. **验证**：刷新页面（Ctrl+F5 强制刷新）——交易时段应显示结算价数字；
   非交易时段显示 "--" 也算对（数据源没给）。
4. **用 git 记录你的第一个前端改动**：
   ```powershell
   git add -A ; git commit -m "feat: 报价头新增结算价显示（练习10）"
   ```

## 检查点

- [ ] 页面上能看到"结算"格子
- [ ] 数字颜色随涨跌变化（或至少正确显示）
- [ ] 用 git 提交了一次
