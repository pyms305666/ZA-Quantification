# 练习11 参考答案（前端加"刷新"按钮）

## 第 1 处：HTML（static/index.html）

工具栏里、"账户"按钮旁边加：
```html
<button id="refresh-btn" class="account-btn">刷新</button>
```
复用 `account-btn` 的样式类——同款外观零成本（样式复用）。

## 第 2 处：JS（static/app.js）

在其他 `addEventListener` 附近加（基础版）：
```js
$("refresh-btn").addEventListener("click", () => {
  loadKline(); loadDecision(); loadInstruments(); loadStatus();
});
```

进阶版（带"刷新中..."反馈）：
```js
$("refresh-btn").addEventListener("click", () => {
  const btn = $("refresh-btn");
  btn.textContent = "刷新中...";
  loadKline(); loadDecision(); loadInstruments(); loadStatus();
  setTimeout(() => { btn.textContent = "刷新"; }, 2000);
});
```
要点：`btn.textContent = ...` 改按钮文字给用户**即时反馈**；
2 秒后 `setTimeout` 恢复——**用户界面必须对每次点击有反应**（否则用户会连点 N 次）。

## 第 3 处：验证

1. F12 打开控制台；
2. 点"刷新"→ 控制台无报错，页面数据更新（更新时间戳变化）；
3. 连续快速点几下——注意每个加载函数会并发跑多次（这正是下一节"竞态"存在的土壤）。

## 思考题参考答案（手动按钮 vs 自动轮询为什么并存）

1. **心理层面**：用户"感觉卡了"的时候，一个能点的按钮给出控制感；
   自动轮询再勤，用户不知道它存在，焦虑不会减少。
2. **功能层面**：轮询间隔是 6s/15s——用户刚切完合约不想等，
   手动刷新是"立即、强制、全量"的重取。
3. **工程层面**：两者共用同一批 load 函数，只是触发方式不同（定时器 vs 点击）——
   这就是为什么把"加载"封装成独立函数：**一个函数，多种触发**。
