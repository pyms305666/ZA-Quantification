> ⚠️ 这次练习会在 GitHub 上创建真实内容——建议用**自己的 fork/测试仓库**演练，或接受它出现在正式仓库。

## 演练内容（按顺序，每步完成后勾选）

### 第 1 步：改版本号
- [ ] 把 `VERSION` 文件内容改成 `1.2.3-exercise`（或任意新号）
- [ ] 同步改 `static/index.html` 的品牌版本号和 `?v=` 参数

### 第 2 步：打包
- [ ] 确认在正确的分支上（选一条路线）
- [ ] 执行 PyInstaller 打包命令（docs/14 §5.4 / README）
- [ ] 确认 `dist/` 里出现了新 exe

### 第 3 步：冒烟测试（5 项全过才算过）
- [ ] 双击 exe 启动，天勤连接成功
- [ ] 页面正常显示（K线/盘口/决策）
- [ ] `/api/v1/status` 的 route 字段是当前路线
- [ ] 关闭后无残留 python 进程
- [ ] exe 文件名里带了正确的路线标记

### 第 4 步：提交
- [ ] `git add` 相关文件（**确认 config.json / .tqsdk 不在其中！**）
- [ ] 提交信息按规范（feat/docs: ...，写明路线）

### 第 5 步：打标签与发布
- [ ] `git tag -a V练习 -m "..."`（起一个不与现有标签冲突的名字）
- [ ] `git push origin <分支> <标签>`
- [ ] 在 GitHub 上为该 tag 创建 Release（写说明）
- [ ] 上传 exe 作为资产
