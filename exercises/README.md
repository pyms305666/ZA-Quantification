# 练习文件夹使用说明

> 这是配套 `docs/10~14` 五本教程的**独立练习区**。
> 每道题都是**可运行的**：补全 TODO 后直接运行，看到全 ✅ 就是通过。

## 怎么做练习

1. 在项目根目录打开终端（`E:\codx project\期货评估器`）；
2. 打开对应练习文件，读懂开头的"目标"和"提示"；
3. 只改 `TODO` 标记的地方，**不要改自检代码**；
4. 运行（示例）：
   ```powershell
   python "exercises/第一课-基础与缓存/练习01-给行情柜加统计.py"
   ```
5. 全部 ✅ → 去 `答案/` 文件夹对照参考答案（**先做完再看答案**）；
6. 把练习文件一起 `git add` 提交，进度留痕。

## 练习文件的通用说明

- 每个文件开头的 `sys.path.insert(...)` 是让练习能引用项目里的 `market/` 等模块——**别删**；
- 自检代码用 `✅/❌` 打印结果，不改它也能运行，但只会看到 ❌；
- 做完的练习可以保留在文件夹里，它们是你学习进度的证明。
