# 第 3 章：接口调用教学 —— 从零学会"前端调后端"

> 这是最重要的一章。学会它，你就掌握了所有前端开发的"发动机"。
> 我们会用三种方式调接口：①浏览器直接看 ②fetch 一次性请求 ③WebSocket 持续推送。
> 学完你应该能独立写出"点击按钮 → 拿到数据 → 显示在页面"的完整功能。

## 3.1 预备知识：HTTP 请求到底是什么

当你在浏览器地址栏输入一个网址按回车，浏览器其实做了一件事：
**向那个服务器发一个请求，然后服务器回一段内容**。

HTTP 请求有几个部分组成（不用背，混个脸熟）：

| 部分 | 例子 | 作用 |
|---|---|---|
| 方法 | `GET` / `POST` | 我想要数据，还是我要提交数据 |
| 地址 | `/api/v1/quote/SHFE.rb2610` | 问哪个资源 |
| 请求体（POST 才有） | `{"symbols":["SHFE.rb2610"]}` | 我要提交的内容 |

后端（FastAPI）收到请求后，处理完会返回：
**状态码**（200=成功，404=没找到，500=服务器出错）+ **响应体**（JSON 数据）。

## 3.2 方式一：用浏览器直接看接口返回（最简单的调接口）

什么都不用写。让服务跑着，浏览器访问：

```
http://127.0.0.1:8000/api/v1/status
```

你看到的 JSON 就是"后端返回的数据"。**前端程序做的事情，就是程序化地完成这个过程**。

## 3.3 方式二：fetch —— 发一次请求，拿一次数据

这是前端调后端最常用的函数。语法就一套，背下来：

```js
// 第一步：发请求，等待响应
const resp = await fetch("http://127.0.0.1:8000/api/v1/status");

// 第二步：把响应体（JSON 文本）解析成 JS 对象
const data = await resp.json();

// 第三步：用数据！data 现在是一个对象，用 .字段名 取数据
console.log(data.connected);   // true
console.log(data.futures_count); // 867
```

**注意三件事**：
1. `fetch` 和 `resp.json()` 都是异步的，**必须 `await`**，否则拿不到数据（拿到一个"未完成的承诺"）。
2. `resp.json()` 是"把 JSON 文本变成 JS 对象"。JSON 和 JS 对象长得像，但不是一回事。
3. 用 `data.字段名` 取数据，字段名必须和后端返回的 JSON 里的键**一模一样**。

### 3.3.1 带参数 GET 请求

有的接口需要参数，比如"查 K 线、指定周期"：

```js
// 周期 300 秒（5分钟），要 200 根
const url = "/api/v1/kline/SHFE.rb2610?period=300&count=200";
const resp = await fetch(url);
const data = await resp.json();

// data.bars 是一个数组，每个元素是一根 K 线
console.log(data.bars[0]);   // {datetime: ..., open: ..., high: ..., low: ..., close: ..., volume: ...}
console.log(data.bars[0].close);  // 第一根K线的收盘价
```

`?` 后面的叫**查询参数**：`参数名=值`，多个用 `&` 连接。

### 3.3.2 带数据 POST 请求

POST = "我要提交东西"，需要带请求体（body）：

```js
const resp = await fetch("/api/v1/subscriptions", {
  method: "POST",                        // 方法改成 POST
  headers: { "Content-Type": "application/json" },  // 告诉后端：我发的是 JSON
  body: JSON.stringify({ symbols: ["SHFE.rb2610"] }),  // 把 JS 对象转成 JSON 文本
});
const data = await resp.json();
console.log(data);   // {subscribed: [...], failed: [...]}
```

这里出现了两个转换函数，**必须分清**：
- `JSON.stringify(对象)` ：**JS 对象 → JSON 文本**（发出去的时候用）
- `resp.json()`        ：**JSON 文本 → JS 对象**（收回来的时候用）

## 3.4 错误处理：请求失败怎么办

网络请求随时可能失败（服务没开、超时、后端报错），所以要包在 try/catch 里：

```js
async function getStatus() {
  try {
    const resp = await fetch("/api/v1/status");
    if (!resp.ok) {
      // resp.ok 是 false 说明状态码不是 2xx（200 成功）
      throw new Error("后端返回错误：" + resp.status);
    }
    return await resp.json();
  } catch (error) {
    console.log("请求失败：", error.message);
    return null;   // 失败返回 null，让调用方决定怎么显示
  }
}
```

**这就是我们项目里 `fetchJSON` 函数的原型**。打开 `static/app.js`，找到 `fetchJSON`，
你会发现它比这个多了"超时取消"（AbortController），但核心就是这三步：发请求→查状态→解析。

## 3.5 方式三：WebSocket —— 持续推送（实时行情）

fetch 是"一问一答"：你问一次，它答一次。
但行情是**持续变化**的，总不能让前端每秒问一次吧？——用 WebSocket。

WebSocket 是一个**长连接的管道**：连上之后，后端有新数据就**主动推**给你。

```
fetch（一问一答）：   前端 ──问──► 后端 ──答──► 前端    （每次都要重新问）
WebSocket（管道）：   前端 ──连接──► 后端 ──推──► 前端 ──推──► 前端 ──推──► ...
```

### 3.5.1 连接 + 收消息

```js
// 第一步：建立连接（注意协议是 ws://，不是 http://）
const ws = new WebSocket("ws://127.0.0.1:8000/ws/market");

// 第二步：连接成功时触发（告诉后端：我要订阅哪个合约）
ws.onopen = () => {
  ws.send(JSON.stringify({ action: "subscribe", symbols: ["SHFE.rb2610"] }));
};

// 第三步：收到消息时触发（后端一推数据，这个函数就执行一次）
ws.onmessage = (event) => {
  const msg = JSON.parse(event.data);   // event.data 是 JSON 文本，解析成对象
  if (msg.type === "quote") {
    console.log("最新价：", msg.data.last);   // 每次行情变化都打印一次
  }
};

// 第四步：断开时触发（自动重连是加分项）
ws.onclose = () => {
  console.log("连接断了");
};
```

### 3.5.2 我们项目里 WebSocket 的消息格式

| 方向 | 消息 | 例子 |
|---|---|---|
| 前端→后端 | 订阅 | `{"action": "subscribe", "symbols": ["SHFE.rb2610"]}` |
| 后端→前端 | 订阅结果 | `{"type": "subscribed", "subscribed": [...], "failed": [...]}` |
| 后端→前端 | 行情推送 | `{"type": "quote", "symbol": "SHFE.rb2610", "data": {"last": 3061, "bid": [...], ...}}` |
| 后端→前端 | 初次快照 | `{"type": "quote_snapshot", ...}` |

打开 `static/app.js` 找 `connectWS` 函数——**我们项目里就是这么写的**，你可以对照着看。

## 3.6 总结：调接口的"肌肉记忆"

```
要数据 → fetch + await + resp.json() + 用 data.字段
要推送 → new WebSocket + onmessage 里处理 msg
会失败 → 包 try/catch
发数据 → method:"POST" + body: JSON.stringify(对象)
```
