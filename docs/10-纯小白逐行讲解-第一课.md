## 第 0 章：读代码之前——五个最基础的问题

**Q1：什么是程序？**
程序就是一个文本文件，里面写着你希望计算机按顺序做的事。计算机从上往下逐行执行。
`main.py` 就是一个文本文件，Python 这个"翻译官"负责把它翻译成计算机的动作。

**Q2：什么是运行？**
"运行 `python main.py`" = 打开翻译官，让它从 `main.py` 第一行开始逐行执行，直到结束或你按 Ctrl+C 停止。

**Q3：什么是终端/命令行？**
一个"打字聊天窗口"：你输入命令，计算机执行并回复。`python main.py`、`pip install xxx` 都是在这里输入的命令。

**Q4：什么是服务器/端口？**
- 本项目启动后，你的电脑上有一个"服务"一直在 8000 号"房间"里待命；
- 浏览器访问 `http://127.0.0.1:8000/api/v1/status`，意思是：
  "本机（127.0.0.1）的 8000 号房间，请把 status 的数据给我"；
- 服务器返回一段叫 **JSON** 的文本，长这样：
  ```json
  {"connected": true, "account": "189****36"}
  ```
  规则：左边是名字（键），右边是值，整包用大括号包住。这就是前后端说话的"通用语"。

**Q5：什么是前端/后端/接口？**
- **后端**：在 8000 号房间干活的 Python 程序（连天勤、算指标、存缓存）；
- **前端**：浏览器里画的页面（HTML/CSS/JS）；
- **接口（API）**：前后端约定的"暗号"——前端发什么请求，后端回什么数据。
  就像餐厅菜单：你按菜单点菜（发请求），厨房（后端）按菜单出菜（回数据）。

## 第 1 章：Python 语法速成（每个概念配项目里真实的一行）

### 1.1 注释——写给"人"看的话

```python
# 唯一持有 TqApi 的客户端
```
`#` 开头的内容计算机**不执行**，是写给读代码的人的说明。好注释解释"为什么"，不解释"是什么"。

```python
"""最新行情内存缓存：HTTP 查询直接读缓存，不触碰 TqSdk。"""
```
三个引号包住的叫**文档字符串**，作用同注释，一般放在文件或函数开头，说明"我是干嘛的"。

### 1.2 导入——借用别人写好的工具

```python
import threading
```
"把 Python 自带的多线程工具箱搬进来用"。之后就能写 `threading.Lock()`。

```python
from .model import MarketQuote
```
"从**同目录**的 model.py 文件里，只把 MarketQuote 这一个工具拿进来"。
点号 `.` 表示"本文件夹"。类比：`import` 是去图书馆借一整架书，`from ... import` 是只借其中一本。

### 1.3 变量——给值起名字

```python
app = FastAPI(title="ZA量化")
```
右边造出一个"网站应用"，左边用 `app` 这个名字记住它。之后写 `app` 就是在用它。
变量就像**贴了标签的盒子**：标签是 `app`，盒子里装着网站应用。

### 1.4 函数——把一段动作打包

```python
def status():
    return {"connected": False}
```
- `def` = 定义函数；`status` 是函数名；括号里是"进去的参数"；
- `return` = 把结果交回去，函数结束；
- 定义时**不执行**，调用 `status()` 时才执行。

### 1.5 类——把数据和动作打包成一个"模具"

```python
class QuoteCache:
    def __init__(self):
        self._data = {}
```
- `class` 定义模具；`__init__` 是"新造一个实例时自动执行的初始化"；
- `self` 指"这个实例自己"；`self._data` 是挂在这个实例身上的盒子；
- 用模具造实例：`cache = QuoteCache()`——可以造很多个，互不干扰。
类比：类是**饼干模具**，实例是压出来的**每块饼干**。

### 1.6 缩进——Python 的命根子

```python
def set(self, quote):
    with self._lock:
        self._data[quote.symbol] = quote
```
Python 用**缩进（行前的空格）表示"谁属于谁"**：
`self._data[...]` 缩进在 `with` 里面，表示它受锁保护；
`with` 缩进在 `def` 里面，表示它是函数的一部分。
**缩进错了，程序的意思就全变了**——同一文件必须用同一种缩进（本项目 4 空格）。

### 1.7 None、异常、类型标注

```python
def get(self, symbol: str) -> Optional[MarketQuote]:
```
- `symbol: str` —— 参数类型标注：symbol 应该是个字符串；
- `-> Optional[MarketQuote]` —— 返回值类型：要么是行情对象，**要么是 None（"没有"）**；
- 标注不给计算机看（不强制），给人和工具看，防止传错东西。

```python
raise TqClientError("命令超时")
```
`raise` = 抛出一个"错误信号"。 analogous 餐厅厨房喊"这道菜做不了！"——调用的人可以选择接住处理，或让它一路炸到顶层。接住用 `try/except`（见 1.8）。

```python
try:
    return future.result(timeout=8.0)
except TimeoutError:
    cmd.abandoned = True
```
`try` 里放"可能出错的动作"；`except TimeoutError` = "如果错的类型是超时，就执行下面这几行"。

### 1.8 `if __name__ == "__main__":`（必考）

```python
if __name__ == "__main__":
    main()
```
意思是：**"如果这个文件是被直接运行的，就执行 main()"**。
被别的文件 import 时不会执行——防止"我只是想借用里面的函数，结果它自己跑起来了"。

## 第 2 章：逐行讲解 `market/cache.py`（37 行，你的第一个完整文件）

> 选它当第一课：它小、真实、一节课能全懂，而且藏着并发编程最重要的一课。

**它干嘛的？** 行情每秒变好几次，很多地方要"最新价"。这个文件就是一个**带锁的柜子**：
键=合约代码，值=最新行情。谁要最新价，直接开柜子拿，不用每次都去问天勤服务器。

```python
"""最新行情内存缓存：HTTP 查询直接读缓存，不触碰 TqSdk。"""
```
第 1 行：文档字符串。翻译："我是缓存，查询请找我，别去打扰天勤连接。"
为什么这么设计？天勤连接又慢又珍贵，最新价早就在本地了。

```python
from __future__ import annotations
```
第 2 行：固定写法，照抄即可。作用是让类型标注的写法更灵活（兼容细节，不影响理解）。

```python
import threading
from typing import Optional
```
第 3~4 行：搬进"锁"工具箱和"Optional（可为空）"标注工具。

```python
from .model import MarketQuote
```
第 5 行：从同目录 `model.py` 导入"标准行情"模板——本文件存的每一条数据都是这个形状。

```python
class QuoteCache:
```
第 6 行：定义模具 QuoteCache（行情柜）。

```python
    def __init__(self) -> None:
```
第 7 行：造新柜子时自动执行的初始化。

```python
        self._data: dict[str, MarketQuote] = {}
```
第 8 行：柜子本体——一个**字典**。字典=键值对集合（像衣柜，每个格子有编号）。
键=合约代码（如 "SHFE.rb2610"），值=整条行情。开头的 `_` 是"内部私有"的命名习惯：请通过方法存取，别直接伸手进柜子。

```python
        self._lock = threading.Lock()
```
第 9 行：一把锁。**为什么需要？** 行情线程在写柜子、网页请求在读柜子，两边同时动手会把字典弄乱（就像两个人同时写同一页账本会写花）。锁 = **一次只让一个人碰**。

```python
    def set(self, quote: MarketQuote) -> None:
        with self._lock:
            self._data[quote.symbol] = quote
```
存入方法。`with self._lock:` 的意思是：**进这间屋子先拿锁，出来自动还锁**。
拿到锁之后把行情放进以它代码命名的格子里。同一时刻只有一个线程在写——这就是"并发安全"。

```python
    def get(self, symbol: str) -> Optional[MarketQuote]:
        with self._lock:
            return self._data.get(symbol)
```
读取方法。`dict.get(键)` 的好处：键不存在返回 None（而不是报错）——"柜子里没这件"不是事故，是正常情况。

```python
    def all(self) -> list[MarketQuote]:
        with self._lock:
            return list(self._data.values())
```
"把柜子里所有东西抄一份给我"。注意 `list(...)` 复制了一份再给——**不给原件**，避免外面翻看时柜子还在被改动。

```python
    def clear(self) -> None:
        with self._lock:
            self._data.clear()
```
清空柜子（断线重连时用——旧数据不可信了）。

```python
    def __len__(self) -> int:
        with self._lock:
            return len(self._data)
```
`__len__` 是特殊方法：定义之后 `len(cache)` 就能直接用（Python 会自动来问它）。

**恭喜，你已经完整读懂了第一个真实文件。** 它教了你：类、方法、self、字典、锁、with、类型标注、私有命名——后面所有文件都是这些语法的组合。

## 第 4 章：逐行讲解一个接口（`/api/v1/status`）

前端右上角"天勤已连接"的数据就来自它。

```python
@router.get("/api/v1/status")
```
**装饰器**（@开头）：把下面这个函数注册成"收到 GET /api/v1/status 请求时执行"。
装饰器=给函数贴标签/加装配件，不用改函数本身。

```python
def status(services: Services = Depends(get_services)) -> dict:
```
- `services: Services = Depends(get_services)`：FastAPI 的**依赖注入**——
  "调用这个函数前，先帮我执行 get_services()，把结果当 services 参数传进来"。
  好处：每个接口都写一行就拿到公共工具箱，不用各自创建。

```python
        futures_count = None
```
先准备一个"未知"占位。

```python
        if services.client.connected:
            try:
                futures_count = len(services.instruments.futures())
            except TqClientError:
                pass
```
若已连上天勤：试着拿合约总数；拿不到（目录还没就绪）就**安静地保持 None**——
状态接口绝不能因为一个小问题炸掉。

```python
        return {
            "connected": services.client.connected,
            "account": mask_account(services.client.account) if services.client.account else "",
            "route": ROUTE_NAME,
            "catalog": catalog,
        }
```
组装 JSON。`mask_account` 把手机号变成 `189****36`——**隐私脱敏**：状态接口谁都能看，不能把完整号码给出去。
`条件 A if 条件 else B` 是 Python 的三元表达式：条件成立取 A，否则取 B。

## 第 5 章：逐行讲解一个业务函数（行情清洗）

`market/processor.py` 里的 `_number`——短小但极其重要：

```python
def _number(value: Any) -> Optional[float]:
```
输入任意东西，输出"干净的数字"或 None。

```python
    if value is None:
        return None
```
本来就空 → 返回空。

```python
    try:
        number = float(value)
    except (TypeError, ValueError):
        return None
```
`float()` 尝试转成数字；转不了（比如值是字符串"abc"）就**转成 None 而不是崩溃**。

```python
    if not math.isfinite(number):
        return None
```
`isfinite` 检查是否为正常数字。金融数据里 NaN（非数字）经常出现，
**一个 NaN 混进图表会让整条线消失**——所以宁缺毋滥。

**这一小段教你**：数据清洗的哲学——外部数据一律不可信，坏数据宁可丢掉也不让它污染下游。

## 第 6 章：前端三样逐行（HTML / CSS / JS）

### HTML（static/index.html）——摆骨架

```html
<div id="qb-last">--</div>
```
一个盒子（div），身份证 `id="qb-last"`（全页唯一，JS 靠它找到这个盒子），
初始内容 `--`（数据没来之前占位）。

```html
<button id="auth-save" class="primary">保存并连接</button>
```
按钮：`class="primary"` 是"衣服款式"（CSS 靠 class 批量打扮）。

### CSS（static/style.css）——穿衣服

```css
#qb-last { font-size: 34px; font-weight: 700; font-family: Consolas, monospace; }
```
`#qb-last` = 选中 id 为 qb-last 的那个盒子；给它大字号、加粗、等宽字体（数字对齐好看）。

```css
:root { --up: #ef5350; }
```
在页面根部定义变量 `--up`（上涨红）。之后任何地方写 `color: var(--up)` 都引用它——
改主题只改一处。

### JS（static/app.js）——大脑，逐行讲 `fetchJSON`

```js
async function fetchJSON(url, options, timeoutMs = 30000) {
```
定义**异步函数**：里面要做"需要等待的事"（网络请求）。async 表示"这个函数可以 await"。

```js
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeoutMs);
```
造一个"取消器"，并定 30 秒的闹钟：到点自动 `abort()`（取消请求）——防止页面一直转圈。

```js
  try {
    const resp = await fetch(url, { ...(options || {}), signal: controller.signal });
```
`await fetch(url)` = 发出网络请求并**在这里等结果**（await 期间页面不卡，别的事照常干）。
`signal` 把取消器接到请求上——闹钟一响请求自动断。

```js
    const body = await resp.json().catch(() => ({}));
```
把服务器返回的 JSON 文本解析成 JS 对象；`.catch(() => ({}))` = 解析失败就当空对象（别崩）。

```js
    if (!resp.ok) throw new Error(body.detail || `HTTP ${resp.status}`);
```
状态码不是 2xx（成功）→ 主动抛错，错误信息优先用后端给的中文 detail。

```js
  } finally {
    clearTimeout(timer);
  }
```
`finally` = 不管成功失败都执行：把闹钟拆掉（清理，防止占资源）。

**这一段教你**：前端调后端的完整姿势=发请求+超时保护+错误处理+清理。

## 第 8 章：黑话大白话词典（持续扩充版）

| 黑话 | 大白话 |
|---|---|
| 接口（API） | 前后端约定的"点菜暗号"：发什么请求，回什么数据 |
| JSON | 带名字的值组成的一包文本，前后端的通用语 |
| 请求/响应 | "我要数据" / "数据给你" |
| 端口 | 本机上的房间号（8000 房间住着本项目的服务） |
| 127.0.0.1 | "本机自己"的门牌号 |
| 服务器 | 一直运行、等人来要数据的一段程序（不一定是一台大机器） |
| 线程 | 程序里的一条"并行干活的工人" |
| 锁 | 一次只许一个人碰的厕所门（保护共享数据） |
| 队列 | 排队取号机：先来先服务 |
| 缓存 | 把刚拿到的数据放柜子里，下次直接拿，不用再跑一趟 |
| TTL | 缓存数据的保质期 |
| 幂等 | 同一件事做几次效果都一样（重复订阅不报错） |
| 竞态 | 两个人同时改一份文件，结果取决于谁先谁后（bug 温床） |
| 死锁/活锁 | 死锁=互相等着都不动；活锁=都在忙但全是无用功 |
| Future | "还没好的结果"的取货凭据 |
| 异步/await | "需要等的事先去办，办完叫我"，期间不卡页面 |
| 协程 | 更轻量的"可暂停任务"，await 时把控制权让出去 |
| 回调 | "事情好了就打这个电话" |
| 装饰器 | 给函数贴标签/加配件的语法（@开头） |
| 依赖注入 | "调用前先帮我把工具备好传进来" |
| 工厂函数 | 进原料、出成品对象的函数（create_app） |
| 归一化/清洗 | 把五花八门的原始数据统一成标准格式、扔掉脏数据 |
| 防腐层 | 在你和外部系统之间放一层翻译，外部怎么变都只影响这层 |
| 防抖 | 连续触发时只认最后一次（搜索框打字 300ms 才查） |
| 重连/重试 | 断了自动再连；失败等会儿再来 |
| WebSocket | 打一次电话持续听的"推送专线"（对比：HTTP 是一问一答） |
| OAuth/Token | 用账号换一张"临时通行证"，之后凭证访问 |
| 打包（PyInstaller） | 把 Python 程序+翻译官+资源塞进一个 exe |
| 仓库/提交/分支 | 项目档案盒 / 存档一次 / 平行世界 |
| Release | GitHub 上的"成品发放处" |

## 遇到看不懂的怎么办（四步读码法）

1. **这行在哪个函数里？**（先看缩进层级）
2. **这行动了哪个数据？**（找 self.xxx / 变量名）
3. **哪个词是语法、哪个词是本项目的东西？**（`def`/`with` 是语法；`QuoteCache` 是项目自己的，去它的定义处看）
4. **还不懂就把这一行贴给我**——逐行讲解就是干这个的。
