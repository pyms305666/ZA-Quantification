## 4.1 `api/http.py`（~290 行）逐段全解

### 4.1.1 导入与常量

```python
import asyncio
from contextlib import asynccontextmanager, suppress
from dataclasses import dataclass, field
from pathlib import Path

from fastapi import APIRouter, Depends, FastAPI, HTTPException, Request
from fastapi.responses import FileResponse, JSONResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel
```
- `asynccontextmanager`：把一个函数变成"进入/退出"两段式的生命周期管理器；
- `Depends`：依赖注入标记（后面用）；
- `HTTPException`：抛出去就是"HTTP 错误响应"（比如 404、503）；
- `BaseModel`（pydantic）：声明请求体的形状，FastAPI 自动校验。

```python
KLINE_PERIODS = {60: "1分钟", 300: "5分钟", 900: "15分钟", 1800: "30分钟", 3600: "60分钟", 86400: "日线"}
DECISION_PERIODS = (86400, 3600, 900, 300)
ROUTE_NAME = "..."
```
周期用**秒数**做主键（86400 秒 = 1 天），名字只用于显示。字典当"合法值清单"用。

### 4.1.2 请求体模型

```python
class SubscribeRequest(BaseModel):
    symbols: list[str]
```
POST 过来的 JSON 必须长这样：`{"symbols": ["SHFE.rb2610"]}`。
少了字段/类型不对，FastAPI 自动返回 422 错误——**校验不用手写**。

### 4.1.3 Services——运行时工具箱

```python
@dataclass
class Services:
    config: Config
    client: TqClient
    instruments: InstrumentManager
    subscriptions: SubscriptionManager
    cache: QuoteCache
    connections: ConnectionManager
    broadcast_queue: asyncio.Queue = field(default_factory=asyncio.Queue)
    loop: Optional[asyncio.AbstractEventLoop] = None
    command_semaphore: asyncio.Semaphore = field(default_factory=lambda: asyncio.Semaphore(8))
```
全项目的"公共工具箱"：配置、行情客户端、目录、订阅、缓存、连接管理器、广播队列。
`field(default_factory=...)`：每个 Services 实例**各自有新的**队列/信号量（直接 `= asyncio.Queue()` 会让所有实例共享同一个——Python 的经典坑）。

```python
    def on_quote_change(self, quote: object) -> None:
        self.cache.set(quote)
        if self.loop is not None:
            self.loop.call_soon_threadsafe(self.broadcast_queue.put_nowait, quote)
```
行情线程回调（在**另一个线程**里执行）：
1. 写缓存；
2. `call_soon_threadsafe`——**跨线程投递**：让 asyncio 事件循环"有空就把行情放进广播队列"。
   直接在别的线程操作 asyncio 的队列是不安全的，所以必须用这个方法。

```python
    async def run_command(self, command, *args, timeout=8.0):
        async with self.command_semaphore:
            return await asyncio.to_thread(self.client.run_command, command, *args, timeout=timeout)
```
**AB 路线的限流关键**：
- `asyncio.to_thread`：把阻塞调用丢进线程池，不卡事件循环；
- `async with self.command_semaphore`：**最多 8 个请求同时在等**——
  如果没有它，几十个超时请求能把线程池（默认 40 线程）全部占满，整个服务假死（本项目真实事故）。

### 4.1.5 路由（逐个接口）

```python
    @router.get("/")
    def index() -> object:
        index_file = static_dir / "index.html"
        if index_file.exists():
            return FileResponse(index_file)
```
访问根路径 = 返回前端页面文件（FileResponse 会自动带文件类型）。

```python
    def require_connected(services: Services) -> None:
        if not services.client.connected:
            raise HTTPException(status_code=503, detail="天勤未连接")
        if not services.client.ready:
            raise HTTPException(status_code=503, detail="天勤连接初始化中，请稍候重试")
```
**守卫函数**：每个需要数据源的接口开头都调用它。把"没连接"和"还在预热"分开说清楚。

```python
    @router.get("/api/v1/kline/{symbol}")
    async def kline(symbol: str, period: int = 300, count: int = 200, services=...):
        require_connected(services)
        if period not in KLINE_PERIODS:
            raise HTTPException(status_code=422, detail=f"不支持的周期：{period}，可选 {sorted(KLINE_PERIODS)}")
        normalized = await services.normalize(symbol)
        ...
        bars = await services.run_command("get_kline", normalized, period, max(30, min(1000, count)), timeout=30.0)
```
- 路径里的 `{symbol}` 是**路径参数**（访问 /kline/SHFE.rb2610 时 symbol="SHFE.rb2610"）；
- `period: int = 300` 是**查询参数默认值**（?period=900 可覆盖）；
- `max(30, min(1000, count))`：**钳位**——不管前端传什么，都限制在 30~1000（防滥用）；
- AB 分支此端点是 `async def` + `await services.run_command`（限流版）。

```python
    @router.get("/api/v1/decision/{symbol}")
    async def decision(...):
        instrument = await asyncio.to_thread(services.instruments.get, normalized)
        if instrument is None:
            if not getattr(services.client, "catalog_ready", True):
                raise HTTPException(status_code=503, detail="合约目录后台下载中，请稍候重试")
            raise HTTPException(status_code=422, detail=f"合约不存在：{normalized}")
```
"目录还没就绪（503，等会儿再试）"和"真不存在（422）"是**两种不同的错**——对前端展示至关重要。

```python
    @router.post("/api/v1/auth")
    def set_auth(body: AuthRequest, services=...):
        save_credentials(account, body.password)
        services.client.set_credentials(account, body.password)
        return {"ok": True, "account": mask_account(account)}
```
登录接口三步：存本地（git 忽略的文件）→ 热重连 → 返回掩码账号。**密码全程不回传**。

### 4.1.6 lifespan 与广播循环

```python
def _lifespan(services: Services):
    @asynccontextmanager
    async def lifespan(app: FastAPI) -> None:
        services.loop = asyncio.get_running_loop()
        broadcast_task = asyncio.create_task(_broadcast_loop(services))
        services.client.start()
        try:
            yield
        finally:
            broadcast_task.cancel()
            with suppress(asyncio.CancelledError):
                await broadcast_task
            services.client.close()
    return lifespan
```
`yield` 之前的代码在**服务启动时**执行，之后的在**关闭时**执行。
- 启动：记下事件循环（跨线程投递要用）→ 启动广播任务 → 启动行情客户端；
- 关闭：取消广播任务（`suppress(CancelledError)` 吞掉取消信号）→ 关闭行情客户端。

```python
async def _broadcast_loop(services: Services) -> None:
    while True:
        quote = await services.broadcast_queue.get()
        await services.connections.broadcast_quote(quote)
```
广播协程一辈子只做一件事：从队列取行情 → 发给所有连接的浏览器。

## 4.2 `api/websocket.py`（93 行）逐行

```python
class ConnectionManager:
    def __init__(self) -> None:
        self._connections: set[WebSocket] = set()
        self._lock = asyncio.Lock()

    async def connect(self, websocket: WebSocket) -> None:
        await websocket.accept()
        async with self._lock:
            self._connections.add(websocket)
```
连接集合 + 锁。`async with`：asyncio 版的 with（进拿锁出还锁）。

```python
    async def broadcast_quote(self, quote: MarketQuote) -> None:
        payload = {"type": "quote", "symbol": quote.symbol, "data": quote.to_dict()}
        async with self._lock:
            targets = list(self._connections)
        for websocket in targets:
            try:
                await websocket.send_json(payload)
            except Exception:
                await self.disconnect(websocket)
```
先复制一份连接列表再遍历（遍历时集合不能变）。发送失败的连接立即移除——**坏连接不拖累广播**。

```python
    @router.websocket("/ws/market")
    async def market(websocket: WebSocket) -> None:
        await services.connections.connect(websocket)
        await websocket.send_json({"type": "hello", ...})
        while True:
            message = await websocket.receive_json()
            action = str(message.get("action", "")).lower()
            if action == "subscribe":
                result = await asyncio.to_thread(services.subscriptions.subscribe, list(symbols))
                await websocket.send_json({"type": "subscribed", **result})
                for symbol in dict.fromkeys(result["subscribed"] + result.get("skipped", [])):
                    cached = services.cache.get(symbol)
                    if cached is not None:
                        await websocket.send_json({"type": "quote_snapshot", "symbol": symbol, "data": cached.to_dict()})
            elif action == "ping":
                await websocket.send_json({"type": "pong"})
```
- 每个浏览器连上来一个独立的 `market` 协程，循环收指令；
- `dict.fromkeys(a + b)`：合并去重且**保序**（Python 字典键不重复且有序）；
- 快照对 skipped 也发——休市时段订阅已存在时页面才能拿到首笔行情（v1.2.1 修复）；
- `WebSocketDisconnect` 异常由外层 `finally disconnect` 收尾。

## 4.3 `static/index.html`（110 行）逐段

```html
<!DOCTYPE html>
```

声明 HTML5 版本；`lang` 告诉浏览器/朗读器这是中文页面。

```html
<link rel="stylesheet" href="/static/style.css?v=1.2.2-c">
```

`?v=` 是**缓存爆破**：文件内容更新时改版本号，浏览器就会重新下载（否则可能一直用旧缓存）。

- 语义化标签：header/section/aside/footer 各有含义（可访问性 + 可读性）；
- `data-period="60"`：**data-* 自定义属性**——把数据贴在元素上，JS 用 `dataset.period` 读。

```html

  <div id="qb-last" class="last-price">--</div>
```

`--` 是占位符：数据没来之前页面不空白也不假。


## 4.5 `static/app.js`（~530 行）逐函数

### 状态与常量

```js
const COLORS = { up: "#ef5350", down: "#26a69a", ... };
const state = { symbol: "SHFE.rb2610", period: 300, kline: [], quote: null, ..., klineReq: 0 };
```
**单一状态源**：页面所有数据都存在 `state`，渲染函数只认 state。
改数据 → 调对应 render 函数。这是最朴素的状态管理（Vue/React 的思想源头）。

```js
const $ = (id) => document.getElementById(id);
```
把最常用的长命令缩写成一个 `$`——**用函数封装重复**。

### fetchJSON（第一课已逐行讲）

补充一行：
```js
    if (external) external.addEventListener("abort", () => controller.abort(), { once: true });
```
`{ once: true }`：监听器触发一次后自动移除（防止内存泄漏）。

### 合约列表

```js
let searchTimer = null;
$("search").addEventListener("input", () => {
  clearTimeout(searchTimer);
  searchTimer = setTimeout(loadInstruments, 300);
});
```
**防抖**：每次按键都重置 300ms 闹钟——停止输入 300ms 才真正发请求。没有它，打一个字发一次请求。

```js
function renderContractList() {
  const list = $("contract-list");
  list.innerHTML = "";
  for (const item of state.instruments) {
    const row = document.createElement("div");
    row.className = "contract-item" + (item.symbol === state.symbol ? " active" : "");
    row.innerHTML = `<span class="c-name">${item.name}</span><span class="c-code">${item.instrument_id}</span>`;
    row.addEventListener("click", () => switchSymbol(item.symbol));
    list.appendChild(row);
  }
}
```
**渲染列表四步**：清空 → 循环造元素 → 绑事件 → 挂到容器。
`row.className = ... + (条件 ? " active" : "")`：当前合约加高亮类。
⚠️ `innerHTML` 直接拼变量有注入风险（本项目数据来自自家后端，风险可控；学规范时改用 `textContent` 更安全）。

### ECharts 图表

### 数据加载与竞态

```js
async function loadKline() {
  const reqId = ++state.klineReq;
  if (state.klineAbort) state.klineAbort.abort();
  const controller = new AbortController();
  state.klineAbort = controller;
  ...

```
**双保险**：序号（响应回来对不对得上当前需求）+ Abort（直接取消还在路上的旧请求）。

### WebSocket

```js
function connectWS() {
  const proto = location.protocol === "https:" ? "wss" : "ws";
  const ws = new WebSocket(`${proto}://${location.host}/ws/market`);
  ws.onopen = () => { ws.send(JSON.stringify({ action: "subscribe", symbols: [state.symbol] })); };
  ws.onmessage = (event) => {
    const msg = JSON.parse(event.data);
    if (msg.symbol !== state.symbol) return;    // 不是当前合约，忽略
    state.quote = msg.data;
    renderQuoteBar(); renderDepth();
  };
  ws.onclose = () => { setTimeout(() => { if (document.visibilityState !== "hidden") connectWS(); }, 3000); };
  ws.onerror = () => ws.close();
}
```
- `document.visibilityState`：页面在后台时不重连（省资源，回前台自然恢复）；
- `onerror → close`：出错主动走 onclose 的重连路径。

### 切换合约

```js
async function switchSymbol(symbol) {
  if (symbol === state.symbol && state.kline.length) return;   // 幂等
  state.symbol = symbol;
  state.quote = null; state.decision = null;                    // 清旧数据
  renderQuoteBar(); renderDepth(); renderDecision();            // 立即呈现"空"状态
  if (state.ws && state.ws.readyState === 1) { ws.send(...) }
  await loadKline();                                            // 等 K 线
  loadDecision();                                               // 决策不用等
}
```
`readyState === 1`：WebSocket 的"OPEN"状态常量。
**await 与不 await 的选择**：K 线是主内容要等；决策慢一点没关系不等——**异步编排的人为控制**。
