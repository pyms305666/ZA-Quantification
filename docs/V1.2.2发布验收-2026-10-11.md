源码 ZIP 不包含被忽略的现场配置、凭据、权重和运行状态；仓库已受跟踪的历史验收记录随源码保留。Windows 沿用已有 C 直连打包形式，没有新增 Electron 安装包。

本版收录七步技术债修复及最终关闭补正，详见 [分步验收](technical-debt/acceptance.md)：

- 两端切换合约立即清空旧数据，取消过时请求；乱序成功、失败和收尾不能覆盖新选择。同参数未完成请求跳过轮询，普通刷新保留缩放。
- 订阅恢复移到可停止线程，失败退避重试；退订版本防止迟到恢复，空订阅表仍发送。Android 后台 wrapper 等待旧受管线程退出后才允许新生命周期。
- 前端共用单连接管理与有限重试；服务端每连接有界 FIFO、慢连接隔离，以及有界行情入口和过载计数。
- 桌面启动统一配置地址、探活期限、受管进程所有权及错误诊断；共享版本资源和 UTF-8 轮转日志。
- 动态漂移、精确依赖锁、冻结守卫、签名及哈希门禁、只读健康检查。

两端 VERSION、页面资源、Electron 应用根版本和 Windows 安装器均为 1.2.2；Android `versionCode` 从 4 增至 5。Electron 依赖版本与完整性摘要不变。APK 门禁读取当前源码版本及 code，拒绝不一致产物；兼容 Windows aapt 中文工作路径和本地化输出编码。

## 保留限制

本版没有执行安装器安装、Android 安装/升级、真机后台生命周期、真实账号登录或开市推送测试。历史 V1.2.1 真机记录不作为 V1.2.2 的设备证据。Windows 安装器和独立 EXE 不具备 Authenticode 签名；独立 EXE 使用内嵌 VERSION，现有 spec 不提供 Windows 文件版本资源。

构建保留 Chaquopy 跳过 `.pyc` 预编译、Gradle/Java 弃用及中文路径开关提示；没有因这些提示升级现场环境。PyInstaller 可选/平台/动态导入提示已与包内必需模块核对；静态检查不能覆盖未执行的功能路径。

已开始的阻塞 HTTP 仍按既有超时自然完成，不能立即强制终止；关闭超时保留旧线程引用。冻结评分、指标、门槛、风险参数、持仓档位和评估输入语义不变。E 盘主工作区和正在运行的验证程序没有被本次修改、启动、停止或重启。
