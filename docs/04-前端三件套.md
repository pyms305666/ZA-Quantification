# 第 4 章：前端三件套 —— HTML / CSS / JS 怎么配合

> 前端页面 = HTML（骨架）+ CSS（衣服）+ JS（大脑）。
> 这一章用我们项目里真实的代码当例子，讲它们各自干什么、怎么配合。
> 学完你应该能看懂 `static/index.html` 和 `static/style.css` 的大致结构。

## 4.1 三个文件，三个角色

| 文件 | 角色 | 类比 |
|---|---|---|
| `index.html` | **骨架**：页面上有什么东西 | 房子的框架、房间布局 |
| `style.css` | **衣服**：东西长什么样 | 墙漆、家具颜色 |
| `app.js` | **大脑**：东西怎么动 | 电灯开关、空调遥控器 |

三者的配合关系：

```
index.html 里摆一个盒子（<div id="qb-last">--</div>）
      ↓ 交给
style.css  给这个盒子定样式（多大、什么颜色、什么字体）
      ↓ 交给
app.js     等数据来了，把 "--" 改成真实价格，还能改颜色
```

## 4.2 HTML：搭骨架

HTML 是一堆**标签**。标签用尖括号包起来，成对出现：

```html
<div id="qb-last" class="last-price">--</div>
```

- `<div>`：一个"盒子"（块级容器，最常用的标签）
- `id="qb-last"`：**身份证号**，一个页面里唯一。JS 靠它找到这个盒子
- `class="last-price"`：**衣服款式**，CSS 靠它批量套样式（可以多个元素共用）
- `--`：盒子里的初始文字（数据没来之前先占位）

我们项目的骨架长这样（`static/index.html`）：

```
<body>
  <header id="toolbar">      ← 顶部工具栏（品牌名 + 周期按钮 + 连接状态）
  <section id="quote-bar">   ← 报价头（合约名 + 最新价 + 今开/最高/最低/成交量…）
  <main id="main">           ← 主体
    <aside id="sidebar">     ← 左边：搜索框 + 自选 + 合约列表
    <section id="chart-area"><div id="chart"></div></section>  ← 中间：K线图画布
    <aside id="right-panel"> ← 右边：五档盘口 + 决策面板
  </main>
  <footer id="statusbar">    ← 底部状态栏
</body>
```

**规律**：`id` 就是 JS 的"寻址"手段。看到 `id="xxx"`，就想到"JS 会通过 `getElementById("xxx")` 找到它"。

## 4.3 CSS：穿衣服

CSS 的语法：**给谁（选择器） 设什么样式**：

```css
#qb-last {              /* # 开头 = 按 id 选 */
  font-size: 34px;      /* 字号 */
  font-weight: 700;     /* 加粗 */
  font-family: Consolas, monospace;  /* 等宽字体（数字整齐） */
}
.last-price {           /* . 开头 = 按 class 选 */
  color: var(--text);
}
```

- `#id` 选一个，`.class` 选一批
- `--text` 是**变量**：在 `style.css` 顶部 `:root { --text: #e8edf2; }` 定义了，全文件都能用。改一个地方，全站变色（这就是"深色/浅色主题"的机制）

## 4.4 JS：大脑（前端核心）

JS 干三件事：**找元素 → 改内容 → 响应事件**。

### ① 找元素

```js
const label = document.getElementById("qb-last");
```

### ② 改内容

```js
label.textContent = "3,061.00";          // 改文字
label.style.color = "#ef5350";           // 改颜色（涨=红）
```

### ③ 响应事件（点击、数据到达、滚动…）

```js
document.getElementById("search").addEventListener("input", () => {
  // 用户每次在搜索框打字，这个函数就执行一次
  loadInstruments();   // 重新去后端查合约
});
```

## 4.5 三件套配合的完整例子（我们项目真实代码）

打开 `static/app.js` 找 `renderQuoteBar` 函数，它演示了完整的"数据→界面"流程：

```js
function renderQuoteBar() {
  const q = state.quote;                    // ① 数据（之前从 WebSocket 收到的行情）
  if (!q) return;                           // ② 没数据就先不动

  // ③ 判断涨跌：最新价 >= 昨结 就是涨
  const up = q.last >= q.pre_close;
  const color = up ? COLORS.up : COLORS.down;

  // ④ 把数据填到界面上：找元素 → 改文字 → 改颜色
  document.getElementById("qb-last").textContent = fmtPrice(q.last, 2);
  document.getElementById("qb-last").style.color = color;
  // ...（今开/最高/最低/成交量同理）
}
```

**流程永远是**：数据在哪 → 界面元素是谁 → 填进去。

## 4.6 本章小结（一个完整小功能怎么写）

假设我们要在页面上加一个"显示天勤连接状态"的小块：

```
第一步（HTML）：在页面加一个盒子
    <div id="tq-status">--</div>

第二步（CSS，可选）：给盒子加样式
    #tq-status { color: #26a69a; }

第三步（JS）：
    async function showStatus() {
      const resp = await fetch("/api/v1/status");
      const data = await resp.json();
      const el = document.getElementById("tq-status");
      el.textContent = data.connected ? "天勤已连接" : "未连接";
      el.style.color = data.connected ? "#26a69a" : "#ef5350";
    }
    showStatus();          // 打开页面就执行一次
    setInterval(showStatus, 15000);   // 每 15 秒再执行一次（保持新鲜）
```

**这就是我们项目 `loadStatus` 函数在做的事**——你现在应该能完全看懂它了。
