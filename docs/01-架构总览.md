# 第 1 章：前后端架构总览 —— "接口"到底是什么？

> 这一章用最直白的话，把整个项目的骨架讲清楚。
> 学完你应该能回答：什么是前端？什么是后端？什么是接口？

## 1.1 一句话认识我们的系统

我们的软件分两半，它们通过"接口"对话：

```
┌─────────────┐     ① 前端发请求       ┌─────────────┐
│   前端       │ ────────────────────► │   后端       │
│ （画界面的）  │                        │ （干活的）    │
│             │ ◄──────────────────── │             │
│             │     ② 后端返回数据      │             │
└─────────────┘                        └─────────────┘
  你看到的：                            你看不到的：
  · K线图、盘口、决策面板                 · 连天勤拿行情
  · 点击、缩放、刷新                      · 计算 K 线指标
                                         · 跑决策引擎
```

- **前端** = 画界面的代码。我们的前端是 `static/` 里的 HTML/CSS/JS。
- **后端** = 干活的代码。我们的后端是 Python 写的 FastAPI 服务（`api/`、`tq/`、`market/`）。
- **接口** = 前后端约定的"暗号"——前端发一个特定请求，后端返回特定格式的数据。

## 1.2 用打电话来理解接口

你打电话订外卖：

| 打电话 | 计算机 |
|---|---|
| 你拨号：**"喂，来一份宫保鸡丁"** | 前端发请求：**GET /api/v1/quote/SHFE.rb2610** |
| 餐厅接单、做好、送过来 | 后端拿到请求，查行情，返回数据 |
| 你收到一份菜 | 前端收到一段 **JSON 数据** |

接口的三要素：
1. **地址**（拨给谁）：`http://127.0.0.1:8000/api/v1/quote/SHFE.rb2610`
2. **方法**（什么事）：`GET`（查询）/ `POST`（提交）/ `DELETE`（删除）
3. **返回的数据**（送回来的东西）：JSON（一种"键值对"文本格式）

## 1.3 看看我们有哪些接口（后端给的"菜单"）

在浏览器打开 http://127.0.0.1:8000 后，前端会调用这些接口。我们打开项目里的 `api/http.py` 能看到它们：

| 方法 | 地址 | 干什么 | 返回什么 |
|---|---|---|---|
| GET | `/api/v1/status` | 问后端"你活着吗？连着天勤吗？" | 连接状态、合约数量 |
| GET | `/api/v1/instruments?keyword=rb` | 查合约列表 | 合约数组 |
| GET | `/api/v1/kline/SHFE.rb2610?period=300&count=200` | 拿 K 线数据 | K 线数组 |
| GET | `/api/v1/quote/SHFE.rb2610` | 拿最新行情 | 最新价、盘口 |
| GET | `/api/v1/decision/SHFE.rb2610` | 让决策引擎评估 | 方向、止损、目标 |
| POST | `/api/v1/subscriptions` | 告诉后端"订阅这个合约" | 订阅结果 |
| WS | `/ws/market` | **持续推送**行情（不是一问一答） | 一条条行情 |

## 1.4 什么是 JSON？（接口返回的"菜"）

后端返回的不是图片、不是文字段落，而是一个叫 **JSON** 的文本。它长得像 Python 的字典：

```json
{
  "symbol": "SHFE.rb2610",
  "last": 3061.0,
  "volume": 336952,
  "open_interest": 1748838
}
```

规则只有两条：
1. 左边是**键**（名字），右边是**值**（数据），用冒号连
2. 多个键值对用逗号隔开，整个用花括号包起来

你可以在浏览器地址栏直接输入 `http://127.0.0.1:8000/api/v1/quote/SHFE.rb2610`，
看到的就是后端"端出来的菜"（一段 JSON）。

## 1.5 前端拿到 JSON 之后做什么？

流程（这就是所有前端页面的本质）：

```
1. 前端用 JS 发请求（fetch 或 WebSocket）
2. 等后端回 JSON
3. 把 JSON 里的数据"填"到界面上（改文字、画图、更新数字）
```

打开 `static/app.js` 搜 `fetchJSON`，你能看到前端发请求的核心函数（第 3 章会逐行讲）。
