# 第 5 章：实战演练 —— 从零写一个"行情卡片"

> 前四章讲的是"零件"，这一章把它们拼起来。
> 我们完全不看现有代码，从空文件开始，写一个能用的东西：
> **在页面上显示螺纹钢的最新价、涨跌、和 5 分钟 K 线的小卡片**。
> 学完你应该能独立完成"查接口 → 画界面"的完整闭环。

## 5.1 先想清楚：这个卡片需要什么

```
┌─────────────────────────────┐
│  SHFE.rb2610  螺纹钢          │
│  3,061.00   +12.00 (+0.39%)  │  ← 数据来自 /api/v1/quote
│  ┌─────────────────────────┐ │
│  │  迷你 K 线图             │ │  ← 数据来自 /api/v1/kline
│  └─────────────────────────┘ │
└─────────────────────────────┘
```

**需求拆解**（这是写任何功能的第一步！）：
1. 要一块地方显示 → HTML
2. 要好看 → CSS（可后补）
3. 要数据 → 调 `/api/v1/quote/SHFE.rb2610`（最新价）和 `/api/v1/kline/...`（K线）
4. 数据到了要填进界面 → JS

## 5.2 第一步：建 HTML 骨架

新建一个文件 `card.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>行情卡片</title>
</head>
<body>
  <!-- ① 占位：名字和价格 -->
  <h2 id="name">--</h2>
  <div id="price" style="font-size:30px;">--</div>
  <div id="change" style="color:#999;">--</div>

  <!-- ② K线图画布（ECharts 会在这里画图） -->
  <div id="chart" style="width:600px;height:300px;"></div>

  <!-- ③ 引入 ECharts（画图库）和我们自己的 JS -->
  <script src="https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js"></script>
  <script src="card.js"></script>
</body>
</html>
```

先别管样式，**结构**对不对最重要。三个 `id`（name/price/change/chart）就是 JS 要操作的"把手"。

## 5.3 第二步：写 JS —— 先调最新价接口

新建 `card.js`：

```js
// ---------- 第一件事：去后端拿最新价 ----------
async function loadQuote() {
  try {
    // 1) 发请求（fetch 是异步的，await 等它）
    const resp = await fetch("http://127.0.0.1:8000/api/v1/quote/SHFE.rb2610");
    const data = await resp.json();     // 2) JSON 文本 → JS 对象

    const q = data.data;                // 3) 数据在 data.data 里（后端返回的结构）
    if (!q) { console.log("还没行情"); return; }

    // 4) 计算涨跌额和涨跌幅
    const change = q.last - q.pre_close;
    const percent = (change / q.pre_close * 100).toFixed(2);

    // 5) 填进界面
    document.getElementById("name").textContent  = q.symbol + "  螺纹钢";
    document.getElementById("price").textContent = q.last.toLocaleString("zh-CN");
    document.getElementById("change").textContent =
      (change >= 0 ? "+" : "") + change.toFixed(2) + " (" + percent + "%)";
  } catch (error) {
    console.log("加载失败：", error.message);
  }
}

// 打开页面就执行一次
loadQuote();
```

**重点回顾**：
- `await resp.json()` 之前，`resp` 只是一个"响应对象"，**数据还没到**；await 之后才有数据
- `q.last`、`q.pre_close` 这些字段名，是**后端接口定义的**（打开浏览器访问接口就能核对）
- `toFixed(2)` = 保留两位小数；`toLocaleString` = 加千分位逗号（3061 → 3,061）

## 5.4 第三步：画 K 线（用 ECharts）

在 `card.js` 后面加：

```js
// ---------- 第二件事：去后端拿K线，画图 ----------
async function loadKline() {
  try {
    const resp = await fetch(
      "http://127.0.0.1:8000/api/v1/kline/SHFE.rb2610?period=300&count=60"
    );
    const data = await resp.json();
    const bars = data.bars;   // 60 根K线，每根 {datetime, open, high, low, close, volume}

    // ECharts 需要的数据格式：X轴标签（时间）+ K线数据（开收低高）
    const times  = bars.map(b => new Date(b.datetime).toLocaleTimeString());
    const ohlc   = bars.map(b => [b.open, b.close, b.low, b.high]);

    // 创建图表（挂到 id="chart" 的盒子上）
    const chart = echarts.init(document.getElementById("chart"));
    chart.setOption({
      xAxis:  { type: "category", data: times },
      yAxis:  { scale: true },            // scale:true 让价格波动看得清
      series: [{ type: "candlestick", data: ohlc }],   // candlestick = 蜡烛图
    });
  } catch (error) {
    console.log("K线加载失败：", error.message);
  }
}

loadKline();
```

**`bars.map(...)` 是什么**：遍历数组每个元素，返回一个新数组。
- `bars.map(b => b.close)` = 取出所有收盘价组成新数组（类似 Python 的列表推导 `[b["close"] for b in bars]`）

## 5.5 完整流程串起来

```
打开 card.html
  ↓
card.js 开始执行（两个函数几乎同时发出请求）
  ├─ loadQuote()  ──fetch──► /api/v1/quote  ──► 填名字/价格/涨跌
  └─ loadKline()  ──fetch──► /api/v1/kline  ──► ECharts 画蜡烛图
```

**这就是前端开发的全部套路**：定义需求 → HTML 摆位置 → JS 发请求 → 数据填进去 → （CSS 美化）。
