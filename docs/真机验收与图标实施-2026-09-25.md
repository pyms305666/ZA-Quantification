## 实施内容

1. `assets/icon-android.svg` 保存桌面图标视觉元素的矢量母版；深色背景、蓝色方块和金色菱形分别绘制。
2. Android API 24/25 使用 `mipmap-anydpi/` 矢量图标；API 26+ 使用 `mipmap-anydpi-v26/` 自适应图标，包含前景、背景和单色层。前台服务通知改用独立的单色小图标。
3. Manifest 设置应用普通及圆形图标；标签改为已有的 `@string/app_name`。
4. 前台服务通知构造器按 API 26 分支选择，避免在工程最低支持的 API 24/25 上调用 API 26 构造器。
