## 发现的问题

1. **Android lint 阻断（需修复）**：`mobile-app/app/src/main/java/com/zaquant/mobile/BackendService.java:43` 使用 `new Notification.Builder(this, CHANNEL_ID)`，该构造器要求 API 26，而工程 `minSdk=24`。在 Android 7.x（API 24/25）启动前台服务时可能抛出兼容性异常。建议按系统版本选择带渠道 ID 与不带渠道 ID 的构造器，再在 API 24/25 和 API 26+ 上分别验证。当前报告仅记录问题，未改代码。
2. **缺少应用图标**：`mobile-app/app/src/main/AndroidManifest.xml` 的 `<application>` 未设置 `android:icon`；新 APK 的 `aapt dump badging` 显示 `icon=''`。这对应 lint 的 `MissingApplicationIcon` 警告。实施步骤见 [手机端图标方案](手机端图标方案-2026-09-25.md)。
3. **其余 5 项 lint 警告**：电池优化豁免申请、WebView 启用 JavaScript、无超时 WakeLock、冗余 SDK 版本判断、未使用的 `app_name` 字符串。应逐项评估；其中后台保活和 WebView JavaScript 与现有功能有关，不宜只为消除警告而直接删除。

## 尚未覆盖的验收

- 没有连接真机；模拟器 API 34/x86_64 的结果不能替代 Android 7.x 兼容性或 vivo 等厂商的锁屏、断网、后台保活验证。
- 只验证 WebSocket 握手与 ping/pong，未在持续活跃交易时段统计实际报价推送频率和长会话稳定性。
- 未测试 Release APK 的模拟器安装与升级路径，也未检查现有 `dist/` 发布包是否与本次源码构建一致。
- 未执行 Electron/PyInstaller 安装器的安装、卸载和升级流程；窗口测试覆盖的是开发态 Electron 壳。

建议先处理 lint 的 API 兼容错误与图标资源，再分别用 API 24/25 模拟器和实际目标手机做安装、登录、行情、K 线、搜索、断网重连与锁屏持续接收验收。需在交易时段记录 `quote_recv_total` 的增长和异常日志。
