## 3.1 `tq/subscriber.py`（98 行）——订阅管理，从它开始

**它干嘛的？** 谁要收某个合约的实时行情，必须先"订阅"。这个文件管理订阅的登记、去重、拒绝。

```python
class SubscriptionManager:
    def __init__(self, client: TqClient, instruments: InstrumentManager) -> None:
        self._client = client
        self._instruments = instruments
        self._subscribed: dict[str, str] = {}   # 原始写法 -> 归一化代码
```
构造时收两个"同事"（行情客户端 + 合约目录），自己只记一本账：
用户输入的写法 → 标准代码（比如你输 `rb2610`，标准是 `SHFE.rb2610`）。

```python
    def subscribe(self, symbols: list[str]) -> dict:
        if not self._client.connected:
            return {"subscribed": [], "skipped": [],
                    "failed": [{"symbol": raw, "reason": "天勤未连接"} for raw in (symbols or [])]}
```
**快失败**：连接没好就别浪费时间，立即把每个合约都标成失败并给原因。
注意返回结构是**三分类**：subscribed（成功）/ skipped（本来就订着）/ failed（失败+原因）——比单纯"成功/失败"表达力强得多。

```python
        for raw in symbols or []:
            normalized = normalize_symbol(self._client, raw)
            if normalized is None:
                failed.append({"symbol": raw, "reason": "合约代码无法解析"})
                continue
```
逐个处理。`normalize_symbol` 把任意写法变成标准代码；解析不了 → 记失败，`continue` 跳到下一个（**一个失败不拖累整批**）。

```python
            if normalized in self._subscribed.values() or normalized in seen:
                if normalized not in seen:
                    seen.add(normalized)
                    skipped.append(normalized)
                continue
```
**幂等性**：已经订过的不再订（skipped）；同一次请求里重复出现也去重（`seen` 集合）。
"重复做和做一次效果一样"——这就是幂等。

```python
            if instrument.expired:
                failed.append({"symbol": raw, "reason": "合约已过期"})
                continue
            if instrument.expire_rest_days is not None and instrument.expire_rest_days <= 1:
                failed.append({"symbol": raw, "reason": f"合约临近交割（剩余 {instrument.expire_rest_days} 天），拒绝订阅"})
```
业务规则：过期的不订；快交割的也不订（快到期合约流动性差、容易逼仓）。
`f"...剩余 {x} 天..."`：f-string 里直接嵌变量。

```python
            try:
                self._client.run_command("subscribe", normalized, timeout=10.0)
            except TqClientError as error:
                failed.append({"symbol": raw, "reason": str(error)})
                continue
            self._subscribed[raw] = normalized
            subscribed.append(normalized)
```
真正执行订阅（发给行情线程），成功才记账。

```python
    def _next_catalog_batch(self) -> Optional[list[str]]:
        with self._lock:
            if self._futures is None:
                return None
            now = time.monotonic()
            pending: list[str] = []
            for symbol in self._futures:
                if symbol in self._info_cache:
```

- 全都查完 → None（"没活了"）。

回写。`zip(batch, records)` 把"查了谁"和"查到的结果"一一配对。整批失败 → 全部进冷却。

```python
def normalize_symbol(client: TqClient, symbol: str) -> Optional[str]:
    value = (symbol or "").strip()
    upper = value.upper()
    if "." in upper:
        exchange, instrument = upper.split(".", 1)
        if exchange in EXCHANGES and instrument:
            return f"{exchange}.{canonical_instrument(exchange, instrument)}"
        return None
    for exchange in EXCHANGES:
        candidate = f"{exchange}.{canonical_instrument(exchange, upper)}"
        try:
            client.run_command("get_instrument", candidate, timeout=8.0)
            return candidate
        except Exception:
            continue
    return None
```

## 3.3 `tq/client.py`（AB 路线核心，~600 行）

### 3.3.1 命令对象与队列

```python
class _Cmd:
    __slots__ = ("command", "args", "future", "abandoned")
    def __init__(self, command: str, args: tuple, future: Future) -> None:
        self.command = command
        self.args = args
        self.future = future
        self.abandoned = False
```
一条命令 = "要调什么 + 参数 + 取货凭据(Future) + 放弃标记"。
`__slots__`：限定对象只能有这四个属性——省内存、防手滑。

```python
    def run_command(self, command, *args, timeout=8.0) -> Any:
        if not self.ready:
            raise TqClientError("天勤连接初始化中，请稍候重试")
        cmd = self.submit(command, *args)
        try:
            return cmd.future.result(timeout=timeout)
        except TimeoutError:
            cmd.abandoned = True
            self._note_command_timeout()
            raise TqClientError(f"命令超时（{timeout:g}s）：{command}") from None
        except Exception as error:
            raise TqClientError(str(error)) from error
```
**全项目最重要的 10 行之一**，逐行：
1. 没就绪就**快速失败**（绝不排队白等）；
2. 把命令扔进队列，拿回凭据；
3. `future.result(timeout=...)`：最多等这么久；
4. 超时 → 给命令贴"已放弃"标签（事件循环看到就跳过）+ 通知计数器（连续 3 次超时触发重连）→ 抛中文错误；
5. 其他异常统一包成 `TqClientError`（对外只有一种错误类型，好处理）。
`raise ... from None`：隐藏内部异常链，让用户只看到干净的一句话。

### 3.3.2 事件循环主线程

```python
    def _run(self) -> None:
        api = None
        while api is None and not self._stop.is_set():
            try:
                api = self._connect()
            except Exception as error:
                self._set_error(str(error))
                self._status(f"天勤登录失败，5 秒后重试：{error}")
                self._fail_pending_commands(TqClientError(f"天勤未连接：{error}"))
                if self._stop.wait(5.0):
                    return
```
首次连接失败**不退出线程**——5 秒后重试（`self._stop.wait(5.0)` 一石二鸟：既是睡眠，又能被"关闭"立即打断）。
为什么要重试？因为启动时可能还没输入账号（登录界面流程）。

```python
        self._status("天勤已连接")
        self._ensure_catalog_worker(api)
        try:
            while not self._stop.is_set():
                if self._reconnect_requested:
                    ...重新连接...
                try:
                    api.wait_update(deadline=time.time() + self._wait_deadline)
                except Exception as error:
                    ...标记等待重连...
                self._process_commands(api)
                self._dispatch_changes(api)
        finally:
            api.close()
            self._set_connected(False)
            self._fail_pending_commands(...)
```
主循环每 0.5 秒转一圈，做三件事：
1. `wait_update`：驱动 TqSdk（等新行情最多 0.5 秒）；
2. `_process_commands`：处理排队的命令；
3. `_dispatch_changes`：检查哪些行情变了，通知上层。
`finally`：无论怎么退出，都关闭连接、清空排队的命令——**清理必须有，且放在 finally**。

```python
    def _process_commands(self, api: Any) -> None:
        while True:
            try:
                cmd = self._commands.get_nowait()
            except queue.Empty:
                return
            if cmd.abandoned:
                continue
            try:
                if cmd.command == "close":
                    cmd.future.set_result(None)
                    self._stop.set()
                    return
                cmd.future.set_result(self._execute(api, cmd.command, cmd.args))
            except Exception as error:
                cmd.future.set_exception(error)
```
`get_nowait()`：不排队等，没命令立即返回（用 `queue.Empty` 判断）。
命令执行成功 → `set_result`（凭据兑现）；失败 → `set_exception`（凭据作废并告知原因）。
**注意**：等待方超时已经放弃了（abandoned）→ 直接跳过，不浪费事件循环时间。

### 3.3.4 目录后台协程（B 路线的"让出"）

`api.create_task`：TqSdk 官方协程模式——把协程挂到 TqApi 的循环上，由主循环 `wait_update` 驱动。

```python

        while not self._stop.is_set():
```

逐行要点：
- `await` 是**协程版等待**——等待期间事件循环照常处理 K 线/订阅命令（这就是"让出"）；
- **绝不能在协程里调用阻塞版 `wait_update`**（会卡死循环）；
- 每批查完睡 50 毫秒，给别的活留空间。

```python
    async def _await_frame(self, api, frame, timeout):
        task = getattr(frame, "_task", None)
        await asyncio.wait_for(asyncio.shield(task), timeout)
```
`asyncio.shield`：**护盾**——wait_for 超时会取消里面的任务，shield 保证 tqsdk 的内部任务不被误杀。

## 3.5 `tqdiff/client.py`（C 路线协程客户端，~530 行）

### 总骨架

```python
    def _run_loop(self) -> None:
        self._loop = asyncio.new_event_loop()
        asyncio.set_event_loop(self._loop)
        try:
            while not self._stop.is_set():
                try:
                    self._loop.run_until_complete(self._session())
                except Exception as error:
                    self._status(f"连接异常，3 秒后重连：{error}")
                self._set_connected(False)
                if self._stop.wait(3.0):
                    break
        finally:
            self._loop.close()
```
独立线程里**新建一个 asyncio 事件循环**并运行会话函数；
会话挂了 → 睡 3 秒 → 整个重连（重新登录）。**外层重连循环 + 内层会话**是网络客户端标准结构。

### 会话：登录 → 连接 → 后台目录

```python
    async def _session(self) -> None:
        token_info = await self._loop.run_in_executor(None, lambda: diff_auth.login(self._account, self._password))
        md_url = await self._loop.run_in_executor(None, lambda: diff_auth.get_md_url(self._token))
        async with websockets.connect(md_url, open_timeout=20, ping_interval=15) as ws:
            self._set_connected(True)
            self._ensure_symbol_file_task()          # 目录下载不阻塞行情！
            await self._send({"aid": "peek_message"})
            async for raw in ws:
                ...处理数据...
                await self._send({"aid": "peek_message"})
```
- `run_in_executor`：把**阻塞的 requests 调用**丢进线程池，`await` 等它——事件循环不被卡；
- `async with websockets.connect(...)`：异步上下文管理器，连接生命周期自动管理；
- **目录下载在连接成功后才启动**（后台任务）——行情/K线先可用（v1.2.1 教训）；
- `async for raw in ws`：持续收消息；每收一批回一条 `peek_message`（协议规定：你不 peek，服务器不推）。

### 命令即协程

```python
    def run_command(self, command, *args, timeout=8.0):
        coro = self._execute(command, args)
        future = asyncio.run_coroutine_threadsafe(coro, self._loop)
        return future.result(timeout=timeout)
```
与 AB 的对比：AB 把命令**排队**让单线程逐个执行；C 把命令**变成协程**并发执行——
命令内部全是"发一条消息 + 等本地状态"，没有长命令，所以不需要队列。
